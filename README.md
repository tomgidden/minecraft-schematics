# Minecraft Schematics

A collection of Minecraft [Litematica](https://github.com/maruohon/litematica)
schematics (`.litematic` files).

## Contents

- **`gid/`** — my own schematics. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **`gid/old/`** — my schematics from much earlier. Same licence, but expect
  older builds, older Minecraft versions, and rougher work.
- **`thirdparty/`** — schematics *of creations by other creators*.

## Usage

Copy the `.litematic` files into your Litematica schematics folder
(`.minecraft/schematics/`), then load them in-game via the Litematica menu.

- [Litematica on Modrinth](https://modrinth.com/mod/litematica)
- [Litematica on Curseforge](https://www.curseforge.com/minecraft/mc-mods/litematica)
